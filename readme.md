## Commands


```
git init
git add <filename>
git add -A
git commit -m "<msg>"
git checkout - b <name>
git checkout <branchName>
git status
git merge <branchName>

git tag -a '<semVer>' -m '<msg>'

git remote add origin <url>
git pull origin <branchName>
git push origin <branchName>
git push origin --tags

git reset --hard <id>
git log
git reflog
```
